# Choropleth chart (New)

> NorthStar component. Category: Data viz. Rules for every component are in https://mikelrosenthal.com/northstar/agent/northstar.md.

A tile map choropleth shows a value by region, one equal square per US state on a 12 by 8 grid, darker squares for more. Equal tiles keep small states as visible as large ones and need no map data. Five sizes cover a KPI tile, a narrow column, the default card, a card with a summary and a wide multi-KPI panel. The plot renders from one description as SVG, and the same description draws the Figma set.

Page: https://mikelrosenthal.com/northstar/#/components/choropleth-chart · Figma node 4792:1292

Classes: `ns-chart`, `ns-chart--small`, `ns-chart--vertical`, `ns-chart__desc`, `ns-chart__desc--sm`, `ns-chart__dot`, `ns-chart__head`, `ns-chart__icon`, `ns-chart__kpi`, `ns-chart__kpis`, `ns-chart__plot`, `ns-chart__summary`, `ns-chart__title`, `ns-chart__title--lg`, `ns-chart__title--sm`, `ns-chart__trend`, `ns-chart__value`, `ns-chart__value--sm`

Figma variants: Size: Small, Vertical small, Medium, Large, XL; Title: Text; Value: Text; Show icon: Boolean

Use:
- A value by US state.
- Spotting regional clusters, not exact numbers.

Avoid:
- Exact values. Use Data table or a ranked Bar chart.
- Regions where shape or distance matters. Use a geographic map.
- Fewer than eight regions. Use Bar chart.

- Do: Axis labels and gridlines on the Medium plot.
- Do not: The compact plot drops axes and labels.

- trend: string, default -. Signed change, for example +2.4%
