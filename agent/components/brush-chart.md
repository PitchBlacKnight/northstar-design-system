# Brush chart (New)

> NorthStar component. Category: Data viz. Rules for every component are in https://mikelrosenthal.com/northstar/agent/northstar.md.

A brush chart pairs a detail plot with an overview strip of the whole series. A window on the strip chooses which months the detail plot shows: drag it to move, drag an edge to resize, press outside it to jump. Five sizes cover a KPI tile, a narrow column, the default card, a card with a summary and a wide multi-KPI panel. The plot renders from one description as SVG, and the same description draws the Figma set.

Page: https://mikelrosenthal.com/northstar/#/components/brush-chart

Classes: `ns-chart`, `ns-chart--small`, `ns-chart--vertical`, `ns-chart__desc`, `ns-chart__desc--sm`, `ns-chart__dot`, `ns-chart__head`, `ns-chart__icon`, `ns-chart__kpi`, `ns-chart__kpis`, `ns-chart__plot`, `ns-chart__summary`, `ns-chart__title`, `ns-chart__title--lg`, `ns-chart__title--sm`, `ns-chart__trend`, `ns-chart__value`, `ns-chart__value--sm`

Figma variants: Size: Small, Vertical small, Medium, Large, XL; Title: Text; Value: Text; Show icon: Boolean

Use:
- Long series where people need both the whole picture and a close look.
- Choosing a period to inspect before drilling in.

Avoid:
- Short series that fit on one plot. Use Line chart.
- Picking exact dates. Use Date picker.

- Do: Axis labels and gridlines on the Medium plot.
- Do not: The compact plot drops axes and labels.

Props (for a component wrapper):

- title: string, default -. Header title
- value: string, default -. Headline figure
- trend: string, default -. Signed change, for example +2.4%
- data: { values: number[], range: [number, number] }, default []. The full series from 0 to 1; range is the window as fractions of the series
- showIcon: boolean, default false. Icon in the header

Keyboard: Tab: Moves focus to the plot; Left or Right arrow: Moves the window one month; Shift with Left or Right: Shrinks or grows the window from its end; Home or End: Moves the window to the start or end

Accessibility:
- The SVG is role="slider" with an accessible name that explains the keys, and aria-valuetext that names the first and last month in the window.
- Dragging also works by touch; vertical swipes still scroll the page.
- Trend text carries its sign, so the color is a second signal.
