# Live line chart (New)

> NorthStar component. Category: Data viz. Rules for every component are in https://mikelrosenthal.com/northstar/agent/northstar.md.

A live line chart shows the last 60 seconds of a stream and slides one step left every second, with a point and halo on the newest value. The card carries a Pause button. Five sizes cover a KPI tile, a narrow column, the default card, a card with a summary and a wide multi-KPI panel; the two compact sizes stay still. The plot renders from one description as SVG, and the same description draws the Figma set.

Page: https://mikelrosenthal.com/northstar/#/components/live-line-chart

Classes: `ns-btn`, `ns-btn--ghost`, `ns-btn--sm`, `ns-chart`, `ns-chart--small`, `ns-chart--vertical`, `ns-chart__desc`, `ns-chart__desc--sm`, `ns-chart__dot`, `ns-chart__head`, `ns-chart__icon`, `ns-chart__kpi`, `ns-chart__kpis`, `ns-chart__pause`, `ns-chart__plot`, `ns-chart__summary`, `ns-chart__title`, `ns-chart__title--lg`, `ns-chart__title--sm`, `ns-chart__tools`, `ns-chart__trend`, `ns-chart__value`, `ns-chart__value--sm`

Figma variants: Size: Small, Vertical small, Medium, Large, XL; Title: Text; Value: Text; Show icon: Boolean

Use:
- Operational metrics that change by the second: requests, queue depth, error rate.
- A monitoring board people watch while something runs.

Avoid:
- Data that changes hourly or daily. Use Line chart.
- A compact tile that cannot fit a Pause button. Use the still Small size.

- Do: Axis labels and gridlines on the Medium plot.
- Do not: The compact plot drops axes and labels.

Props (for a component wrapper):
- size: 'small' | 'vertical-small' | 'medium' | 'large' | 'xl', default 'medium'. Layout and plot size
- title: string, default -. Header title
- value: string, default -. Headline figure
- trend: string, default -. Signed change, for example +2.4%
- data: { t: number, value: number }[], default []. The last 30 samples, oldest first, value from 0 to 1
- showIcon: boolean, default false. Icon in the header

Keyboard: Tab: Moves to the Pause button; Enter or Space: Pauses or resumes updates

- The SVG is role="img". The headline value is not a live region, so a screen reader is not interrupted every second.
- The Pause button names its action and changes to Resume while paused.
- Trend text carries its sign, so the color is a second signal.
