# Composed chart (New)

> NorthStar component. Category: Data viz. Rules for every component are in https://mikelrosenthal.com/northstar/agent/northstar.md.

A composed chart draws two measures with different units on one time axis: a count as bars on the left scale and a rate as a line on the right scale. Five sizes cover a KPI tile, a narrow column, the default card, a card with a summary and a wide multi-KPI panel. The plot renders from one description as SVG, and the same description draws the Figma set.

Page: https://mikelrosenthal.com/northstar/#/components/composed-chart · Figma node 4792:506

Classes: `ns-chart`, `ns-chart--small`, `ns-chart--vertical`, `ns-chart__desc`, `ns-chart__desc--sm`, `ns-chart__dot`, `ns-chart__head`, `ns-chart__icon`, `ns-chart__kpi`, `ns-chart__kpis`, `ns-chart__plot`, `ns-chart__summary`, `ns-chart__title`, `ns-chart__title--lg`, `ns-chart__title--sm`, `ns-chart__trend`, `ns-chart__value`, `ns-chart__value--sm`

Figma variants: Size: Small, Vertical small, Medium, Large, XL; Title: Text; Value: Text; Show icon: Boolean

Use:
- A volume and a rate that explain each other.
- Orders and conversion, tickets and resolution time.

Avoid:
- Two measures with the same unit. Use Line chart or Bar chart.
- Unrelated measures. Use two charts side by side.

- Do: Axis labels and gridlines on the Medium plot.
- Do not: The compact plot drops axes and labels.
