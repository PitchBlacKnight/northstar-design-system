# Profit and loss chart (New)

> NorthStar component. Category: Data viz. Rules for every component are in https://mikelrosenthal.com/northstar/agent/northstar.md.

A profit and loss chart is a line around a zero baseline: the part above zero is a gain, the part below is a loss. The line splits where it crosses zero, so each piece takes one color. Five sizes cover a KPI tile, a narrow column, the default card, a card with a summary and a wide multi-KPI panel. The plot renders from one description as SVG, and the same description draws the Figma set.

Page: https://mikelrosenthal.com/northstar/#/components/profit-loss-chart

Classes: `ns-chart`, `ns-chart--small`, `ns-chart--vertical`, `ns-chart__desc`, `ns-chart__desc--sm`, `ns-chart__dot`, `ns-chart__head`, `ns-chart__icon`, `ns-chart__kpi`, `ns-chart__kpis`, `ns-chart__plot`, `ns-chart__summary`, `ns-chart__title`, `ns-chart__title--lg`, `ns-chart__title--sm`, `ns-chart__trend`, `ns-chart__value`, `ns-chart__value--sm`

Figma variants: Size: Small, Vertical small, Medium, Large, XL; Title: Text; Value: Text; Show icon: Boolean

Use:
- Net results that move above and below zero.
- Profit and loss, budget variance, net promoter swings.

Avoid:
- Values that never go below zero. Use Line chart.
- Many series. Each one needs its own zero line.

- Do: Axis labels and gridlines on the Medium plot.
- Do not: The compact plot drops axes and labels.
