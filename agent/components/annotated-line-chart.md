# Annotated line chart (New)

> NorthStar component. Category: Data viz. Rules for every component are in https://mikelrosenthal.com/northstar/agent/northstar.md.

An annotated line chart is a line chart with overlays that explain it: shaded weekends, a goal band, a deadline, a marker on the peak and a dashed projection. Every overlay is a shared helper in NS.chartKit.H, so any chart can use them. Five sizes cover a KPI tile, a narrow column, the default card, a card with a summary and a wide multi-KPI panel. The plot renders from one description as SVG, and the same description draws the Figma set.

Page: https://mikelrosenthal.com/northstar/#/components/annotated-line-chart

Classes: `ns-chart`, `ns-chart--small`, `ns-chart--vertical`, `ns-chart__desc`, `ns-chart__desc--sm`, `ns-chart__dot`, `ns-chart__head`, `ns-chart__icon`, `ns-chart__kpi`, `ns-chart__kpis`, `ns-chart__plot`, `ns-chart__summary`, `ns-chart__title`, `ns-chart__title--lg`, `ns-chart__title--sm`, `ns-chart__trend`, `ns-chart__value`, `ns-chart__value--sm`

Figma variants: Size: Small, Vertical small, Medium, Large, XL; Title: Text; Value: Text; Show icon: Boolean

Use:
- A trend that needs context: a goal, a deadline, a known event.
- Showing what is measured and what is forecast in one plot.

Avoid:
- More than three overlays on a small card. The data gets lost.
- A plain trend. Use Line chart.

- Do: Axis labels and gridlines on the Medium plot.
- Do not: The compact plot drops axes and labels.

Tokens: `--ns-chart-series-1` (Data line, projection and peak marker), `--ns-chart-series-2` (Goal band at 14%), `--ns-widget-band` (Weekend spans), `--ns-chart-target` (Deadline and trend line), `--ns-widget-bg` (Card surface), `--ns-border-subtle` (Card stroke and summary divider), `--ns-chart-label-text` (Axis labels and description), `--ns-status-success` (Trend), `--ns-radius-xl` (Card radius)

Props (for a component wrapper):
- size: 'small' | 'vertical-small' | 'medium' | 'large' | 'xl', default 'medium'. Layout and plot size
- title: string, default -. Header title
- value: string, default -. Headline figure
- trend: string, default -. Signed change, for example +2.4%
- data: { values: number[], projection: number[], goal: [number, number], deadline: number, marks: { at: number, label: string }[] }, default []. Values from 0 to 1; deadline and marks are indexes into values
- showIcon: boolean, default false. Icon in the header

Keyboard: -: Not interactive

Accessibility:
- The SVG is role="img" with a label that names every overlay. Provide a table that marks which values are projected.
- Measured and projected values differ by dash, not only color.
- Trend text carries its sign, so the color is a second signal.
